# Scope and delivery control

## Purpose
Use this skill when a feature request grows into multiple unrelated initiatives. It identifies the smallest useful outcome without discarding user intent.

## Procedure
1. Capture the user goal, non-goals, acceptance criteria, and constraints.
2. Divide ideas into required now, valuable later, blocked pending evidence, and explicitly excluded.
3. Flag assumptions that would change cost, risk, privacy, or timeline if false.
4. Propose a thin vertical slice and a measurable definition of done.
5. Keep deferrals visible so they are not silently lost.

## Output
Return a scoped delivery brief with goal, exclusions, acceptance criteria, risks, dependencies, and next decision.

## Safety boundary
This skill does not make product, financial, medical, legal, deployment, or procurement decisions. It produces a reviewable draft only.
