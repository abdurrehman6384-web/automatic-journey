# Lawful media prompt planning

## Purpose
Use this skill to prepare an original media brief or prompt while respecting intellectual-property, likeness, consent, and asset-retention boundaries.

## Procedure
1. Ask for the intended format, audience, and original creative goal.
2. Identify names, logos, characters, voices, private people, or supplied assets that need rights or consent review.
3. Replace risky references with original descriptive attributes rather than imitating protected identities.
4. Separate a text-only brief from any later media upload, generation, edit, render, or export action.
5. Add a human review point for claims about ownership, permissions, or distribution.

## Output
Return an original creative brief with rights assumptions, excluded references, safe alternatives, review checklist, and a no-generation declaration.

## Safety boundary
No generation provider, model, reference asset, upload, download, render, file write, or publication action is enabled by this skill.
